# AUTOSAR Cruise Control and Emergency Braking System

## Project Overview
An academic automotive software project implementing
Cruise Control and Emergency Braking functionality
using AUTOSAR Classic architecture.

## Key Features
- Cruise Control
- Emergency Braking
- Target Speed Management
- Vehicle Speed Monitoring
- Accident Recording

## Technologies & Tools
- AUTOSAR Classic
- C Programming
- Vector SystemDesk
- Vector VEOS
- Runtime Environment (RTE)

## Software Components
- CruiseControlSWC
- EmergencyBrakeSWC
- TargetSpeedControl
- EngineControl
- AccidentRecorder
